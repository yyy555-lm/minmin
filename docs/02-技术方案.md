# 02 - 技术方案

## 技术选型

| 层级 | 技术 | 说明 |
|------|------|------|
| 桌面框架 | Electron 28+ | 将 Web 应用打包为 Windows EXE |
| 前端框架 | React 18 | 组件化 UI 开发 |
| 语言 | TypeScript 5 | 类型安全 |
| 构建工具 | Vite 6 | 快速开发构建 |
| 样式 | CSS Variables | 粉色主题变量管理 |
| 数据存储 | JSON 文件 | 存放于 OneDrive 同步目录 |
| 打包工具 | electron-builder | 生成 Windows 安装包 |

## 为什么选择这个方案

1. **Electron**: 将网页打包成桌面 EXE，用户双击即可打开，像真正的 Windows 软件
2. **React + TypeScript**: 组件化开发，代码清晰好维护
3. **JSON 文件存储**: 简单可靠，配合 OneDrive 实现同步，不需要搭建服务器
4. **Vite**: 开发时热更新快，构建也快

## 数据同步架构

```
小红电脑                     OneDrive 云盘              小明电脑
┌──────────┐              ┌──────────┐              ┌──────────┐
│ 遇敏 APP │──写入/读取──→│ data.json│←──写入/读取──│ 遇敏 APP │
└──────────┘              └──────────┘              └──────────┘
```

- 两人使用同一个 OneDrive 账号，或通过共享文件夹
- 应用启动时从 OneDrive 文件夹读取 `data.json`
- 每次操作后立即写入文件
- OneDrive 自动将文件同步到云端和另一台电脑

## 性能考虑

- 照片使用 base64 存储，单张照片压缩至 200KB 以内
- 相册缩略图使用 CSS 控制尺寸，不额外生成缩略图
- 数据文件预计大小：100张照片 ≈ 20MB
