## 阶段1: 项目脚手架搭建

**目标**: 创建 Electron + React + TypeScript + Vite 项目骨架，能在浏览器中运行。

**具体任务**:
1. 使用 Vite 创建 React + TypeScript 项目
2. 安装 Electron 和 electron-builder 依赖
3. 创建 electron/main.js 主进程文件
4. 配置 vite.config.ts 支持 Electron
5. 创建基础 App.tsx（仅显示标题）
6. 验证: `npm run dev` 能在浏览器中看到画面

**验证标准**:
- [ ] 能在浏览器中看到粉色背景的应用窗口
- [ ] 控制台无报错

## 阶段2: 密码登录 + 导航框架

**目标**: 实现密码设置/输入页面，以及底部 4 个 Tab 导航框架。

**具体任务**:
1. 实现 PasswordPage 组件（密码设置 + 验证）
2. 实现数字键盘组件
3. 实现底部 TabBar 组件（纪念日/相册/日记/秘密）
4. 实现页面切换逻辑
5. 实现 localStorage 数据持久化
6. 编写 useAppData hook

**验证标准**:
- [ ] 首次打开显示设置密码
- [ ] 设置后可输入密码进入
- [ ] 4个Tab 可正常切换
- [ ] 刷新后密码保持
