# 05 - 数据模型

## 核心数据结构

```typescript
// ====== 类型定义 ======

// 心情
type Mood = 'happy' | 'love' | 'touched' | 'miss' | 'normal';

// 照片
interface Photo {
  id: number;           // 时间戳
  data: string;         // base64 编码
  name: string;         // 原始文件名
  date: string;         // ISO 日期字符串
}

// 日记
interface Diary {
  id: number;           // 时间戳
  title: string;        // 标题
  content: string;      // 内容
  mood: Mood;           // 心情
  date: string;         // ISO 日期字符串
}

// 留言
interface Note {
  id: number;           // 时间戳
  text: string;         // 内容
  date: string;         // ISO 日期字符串
}

// ====== 应用数据 ======
interface AppData {
  appPassword: string;          // 主密码（6位数字）
  privatePassword: string;      // 私密空间密码
  anniversary: string;          // 纪念日 "YYYY-MM-DD"
  albums: Photo[];              // 公共相册
  diaries: Diary[];             // 恋爱日记
  privateNotes: Note[];         // 私密留言
  privatePhotos: Photo[];       // 私密照片
}
```

## 默认值

```typescript
const DEFAULT_DATA: AppData = {
  appPassword: '',
  privatePassword: '',
  anniversary: '',
  albums: [],
  diaries: [],
  privateNotes: [],
  privatePhotos: [],
};
```

## 存储位置

| 环境 | 路径 |
|------|------|
| 开发阶段 | `localStorage` (key: `yumin-app-data`) |
| 桌面 EXE | `%USERPROFILE%/OneDrive/遇敏/data.json` |

## 存储限制

- localStorage: 约 5-10MB
- JSON 文件: 无硬限制，建议照片控制在 200KB/张以内
- 100 张照片预计占用 20MB
