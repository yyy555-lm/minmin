# 01 - 需求文档

## 项目背景
"遇敏"是一款 Windows 桌面恋爱应用，专为情侣设计。提供纪念日记录、情侣相册、恋爱日记和私密空间等功能。应用为桌面 EXE 程序，数据可两人同步。

## 目标用户
- 恋爱中的情侣
- 不需要技术背景，双击即可使用

## 功能清单

### F1 - 密码保护
- **首次使用**: 设置 6 位数字密码
- **每次启动**: 输入密码才能进入
- **密码重置**: 忘记密码时可重置（清空所有数据）

### F2 - 纪念日
- 设置在一起的日期
- 实时显示"我们已经在一起 XXXX 天"
- 爱心飘落动画效果
- **提醒**: 纪念日前1天和当天弹出 Windows 通知

### F3 - 情侣相册
- 从本地选择照片上传
- 三列网格展示照片
- 点击照片全屏查看
- 支持删除照片
- 照片存储为 base64 编码

### F4 - 恋爱日记
- 写日记（标题 + 内容 + 心情）
- 时间线样式展示
- 按日期排列
- 支持删除日记

### F5 - 私密空间
- 需要独立密码进入（默认与主密码相同）
- **留言板**: 两人可以写留言
- **私密相册**: 独立于公共相册的私密照片
- 两人共享同一个私密空间

### F6 - 数据同步
- 数据文件存放在 OneDrive 同步文件夹
- 两人共用同一份数据
- 启动时自动读取最新数据

## 用户使用场景

1. 小明双击桌面"遇敏"图标打开应用
2. 输入共同密码进入
3. 在纪念日页面看到"我们已经在一起 520 天"
4. 切换到相册，点击"添加照片"上传合照
5. 切换到日记，写下今天的约会心情
6. 切换到秘密，输入私密密码，查看留言板
7. 小红的电脑上（通过 OneDrive 同步）也能看到小明上传的照片和日记
